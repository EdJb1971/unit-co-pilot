# Unit Co-Pilot — Local facilitator helper

This repository contains a small Vite + React + TypeScript app for creating and editing brief session plans with the help of a local LLM client. It is designed to run entirely locally (no server-side storage required) and focuses on human-in-the-loop editing, privacy-preserving Vent Mode, and easy packaging for offline distribution.

**Highlights**
- Chat-driven session editing (propose → review → apply) with audit records and optional transcript deletion.
- Vent Mode: ephemeral, privacy-first chat for staff with local safety checks.
- Printable participant handouts generated by the LLM (`generateExpandedSession`).
- Packaging scaffolds for PWA, Electron (Windows), and Capacitor (Android).

## Quick start (developer)

Prerequisites:
- Node.js (recommended 18+) and npm
- Optional: Windows build tools if you need to install native modules like `sharp`

Steps:
1. Install dependencies:

```powershell
npm install
```

2. (Optional) Generate icons used for Windows builds and PWA:

```powershell
npm run generate:icons
```

3. Provide your Gemini API key (used by `services/geminiService.ts`) by creating `.env.local` in the project root with:

```text
GEMINI_API_KEY=your_api_key_here
```

4. Start the dev server:

```powershell
npm start
# or
npm run dev
```

5. Open the app at the URL Vite prints (usually `http://localhost:5173`).

## Available npm scripts
- `start` / `dev` — run Vite dev server
- `build` — build production assets (outputs to `dist/`)
- `preview` — preview production build locally
- `generate:icons` — create PNG sizes and `icons/icon.ico` for Windows builds
- `electron:dev` / `electron:build` — scaffolds for Electron development and build (see notes below)

## Key features & where they live
- Chat-driven propose/review/apply: UI in `components/ChatModal.tsx` + `components/ChangeReviewModal.tsx`, orchestrated by `components/SessionCard.tsx`.
- LLM helpers: `services/geminiService.ts` — functions: `generateDailyPlan`, `generateExpandedSession`, `proposeSessionEdits`, `regenerateSession`, `generateResource`, and `chatVent`.
- Local persistence: `services/storageService.ts` — plan storage, expanded-session cache, chat transcripts, scheduled deletion, change records, and plan versions.
- Vent Mode UI: `components/VentModal.tsx` — ephemeral by default and uses `chatVent`.
- Packaging scaffolds: `electron/main.js`, `electron/preload.js`, `scripts/generate-icon.cjs`, PWA manifest and service worker.

## Data privacy & safety
- All user data (plans, transcripts, expanded sessions) is stored locally in `localStorage` by default.
- `chatVent` applies local safety heuristics and will not forward clear self-harm/first-person crisis content to the LLM; it returns crisis-aware guidance instead.
- Proposed changes from the LLM are never applied automatically — a human must review and accept them before the app persists any edits.

## Packaging notes
- Electron: scaffolding and `electron-builder` config are included; run `npm run electron:build` locally to produce Windows installers. You must have `icons/icon.ico` (created by `npm run generate:icons`) and proper build toolchain installed.
- Capacitor / Android: a basic scaffold is present, but full APK generation requires Android Studio and a local build step.

## Troubleshooting
- If `npm install` fails when building native modules like `sharp`, install the Windows build tools (Visual Studio Build Tools) or remove `sharp` from `devDependencies` if you do not need icon generation.
- If Vite fails with TypeScript errors, the console shows the file and line number. Paste the error here and I can patch the offending file.
